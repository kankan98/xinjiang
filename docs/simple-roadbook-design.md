# 简易版攻略与打包方案

2026-09-30

目标：用更少的页面层级速览十天行程，并保留执行条件。完整版继续承载照片、地图、搜索、预算工具、专题和来源。

## 页面设计

- 顶部：旅行日期、人数、住宿晚数、计划里程及驾驶预算；明确含估算、纯驾驶不含餐休等口径。
- 日期导航：桌面一行十日，手机两行五日，固定在顶部，原生锚点定位。
- 每日卡：日期、路线、主选驾驶读数、住宿及关键提醒默认可见；当天安排、条件备选、完整时间表、吃穿建议按需展开。
- 行前条件：复用七项准备，展开查看确认内容、失败分支和完整版入口。
- 简化阅读：系统字体、暖白与陶土色、自动跟随系统深色外观，无照片或地图依赖。桌面双列，手机单列，正文不截断。
- 离线与打印：单个 HTML 内联 CSS，原生 details，无 JavaScript 必需依赖。浏览器打印时显示折叠内容；完整版跳转需配套站点。

## 构建策略与数据职责

`tools/simple-roadbook.mjs` 提供一个渲染入口；Vite 插件在 `generateBundle` 输出 `dist/simple.html`，与 `dist/index.html` 一同交付。开发服务器的 `/simple.html` 使用同一渲染入口，无需手工同步根目录 HTML。

继续沿用 `pnpm run build`：先生成路线图、搜索索引、每日时间表，完成内容校验，再生成两个页面。不新增线上 API，不维护第二套行程文案。任何每日数据缺失都会使简易版构建失败。

| 内容 | 来源 |
| --- | --- |
| 日期、路线、住宿、摘要、里程及准备条件 | `src/data/roadbook-runtime.json` |
| 日卡标题与章节标识 | `src/data/roadbook.manifest.json` |
| 关键提醒、吃穿建议及适用边界 | `src/data/daily-guides.json` |
| 时间、事件与备注 | `src/generated/day-schedules.generated.json`，由正式正文第一张时间表生成 |
| 简易版样式 | `src/assets/styles/simple.css`，仅内联进简易页，不引入完整版样式 |

日程保留完整时间文字、事件与备注，不用 `key` 筛选（D7/D8 没有 key 标记）。总里程和修订日期直接采用 runtime。D7 估算说明默认显示；D3/D8 的时间限制保留在关键提醒。详情列出备选条件，不把条件分支叠加为主线。

完整版首页提供“简易版速览”；简易版使用相对 `./index.html#/chapter/...` 链接回对应章节，支持子目录部署。

## 验收

`tests/e2e/simple-roadbook.spec.js` 覆盖单文件禁用 JavaScript 阅读、逐项源数据对照、十日链接、关键时间限制、320/390/768/1440 像素布局、键盘展开、深色、打印以及双向导航。配合已有内容校验、单元测试和端到端测试。构建后从 `dist/` 验收。

# RoadBook v3.9 视觉与交互约定

更新于 2026-09-10。本文件描述当前实现。全局设计原则、色彩与参考来源见根目录 [DESIGN.md](../DESIGN.md)：从 awesome-design-md 中的 Airbnb、Claude、Linear 设计分析提取适合中文旅行手册的原则。

## 页面结构

首页依次为板块导航、编辑式标题与秋日摄影、四项旅行规模、十日路线、每日速查、美食卡、预算、沿途影像、行前准备、行李建议与三卷章节索引。十日路线桌面为两列卡片，手机为单列，直接显示规划驾驶时间与里程。手机顶部保留可横滑的板块导航，底部保留目录、搜索、日程和主题操作。

正式章节提供标题摘要、授权图片、三项阅读重点、当日概要、卷内章节入口、日地图、正文及清单；手机先呈现重点，再显示图片。吸顶工具栏提供返回索引、大字阅读和手机本章导航。H2/H3 始终可读，标题有稳定 ID；小节目录直接定位，不要求先展开正文。首页长说明用原生 details，日期用 tabs，目录和图片使用独立对话层。

## 颜色与文字

- 日间使用暖白纸面、炭色正文和陶土橙操作；夜间使用森林灰黑底、浅色正文和杏橙强调。预算基线使用独立深绿色表面。
- 图片压字使用独立浅色令牌，两主题切换时不随纸面正文变暗。
- 中文正文使用系统黑体栈；首页、板块与章标题用宋体；Barlow Condensed 用于大号日期和里程，JetBrains Mono 用于简短编号。
- 正文标准 16px、大字模式 18px，说明文字随模式同步放大，表格大字模式为 16px。时间读数与地图图例保留独立尺度；时刻不能在数字中间换行。打印使用独立字号。
- 颜色不是唯一提示，条件与待确认状态需要配文字。主题图标同时更新可访问名称。

## 阅读和交互

1. 首页当前天的重点、住宿和执行边界始终可见；吃穿住行玩及完整时刻按需展开。
2. 十天标签使用 tablist / tab / tabpanel、方向键、Home / End 与 roving tabindex，并提供上一天、下一天及首末日禁用状态。切换后保存到本机，刷新时将选中标签露出，不带动整页滚动。
3. 预算显示已订基线、明确假设、未知费用和试算小计。空白未知项与填入 0 元有不同含义；清空假设恢复默认估算。
4. 准备清单显示真实本地勾选进度，提示勾选并不完成外部业务。新版清单不沿用旧版序号的完成状态。
5. 按钮和关键链接留出至少 44px 操作区。关闭抽屉、搜索或地图后恢复焦点；键盘焦点可见。
6. 首页跳转不改变 hash 路由；章节内链带真实段落 ID；品牌始终回首页顶部。
7. 首页板块随滚动高亮，选中入口在横向导航中自动露出。从每日章节打开手机速查时沿用对应日期。
8. 搜索提供常用关键词、最近搜索、清空与空结果反馈。方向键选择结果，Home / End 保留文本光标操作，Enter 在建议词上只填入关键词。
9. 大字阅读通过 `roadbook:planner:v3.9:reader-size` 保存。章节条和目录自动跟随时，仅移动各自滚动容器。

## 路线与时间表

每日概要卡片先显示路线，再显示距离与车程；“今晚住宿”独立占满一行，评分区放在下方。酒店名称、金额与预订状态自然换行，禁止用省略、裁切或叠放隐藏信息。布局按阅读列的可用宽度排布，不因浏览器视口变宽而强行并排。

日地图在手机默认收起，展开后自适应宽度。手机标题、里程摘要与首站导航分行，箭头留在折叠按钮右侧；SVG 和图例均受自身容器宽度约束，横竖屏切换后重新适配。折线中的出租车与自驾明确区分，往返计两次，条件独库以虚线表达估算。导航仅跳实际单段或首个自驾目的地。地图原始查询数据与正文保守排程有差异时就地解释。

正式时间表转换为垂直时间轴，但不删掉“约”“次日”“不晚于”等文字。D7 主线与备线分别保留自己的日程和语义标签。首页默认时刻从章节自动提取，避免人工维护两套时间表。

## 响应式与打印

宽表只在自身容器横滚，页面不横向溢出。手机日期条与章节条可横滑；标题、计数和右侧操作按断点换行。验收宽度为 320、375、390、768、1024、1279、1280、1440px。

打印强制白底深字，隐藏全局操作、悬浮按钮与目录，强制展开日地图，保留正文表格和时间轴。遵循 reduced-motion，关闭不必要的动画与平滑滚动。

## 样式维护

`src/assets/styles/roadbook.css` 按顺序载入：

| 文件 | 范围 |
| --- | --- |
| `00-tokens.css` | 明暗主题、语义色、字体、尺度和基础样式 |
| `10-shell.css` | 全局头部、抽屉、搜索、移动底栏和页脚 |
| `20-home.css` | 主图、路线列表和章节索引 |
| `30-reader.css` | 阅读器、正文、日地图和章节目录 |
| `40-patterns.css` | 表格、时间轴、提示、清单和媒体 |
| `50-experience.css` | 每日速查、美食、预算、准备与行李建议 |
| `60-reading-focus.css` | 章首重点、正文语义标记与时间轴层级 |
| `90-print.css` | 打印覆盖 |

修改基础组件时优先改其所属规则，不用新增覆盖层修补。打印、第三方功能组件与 reduced-motion 必要时可使用明确的定向覆盖。

本轮验收使用 `node tools/screenshot-redesign.mjs`，默认连接 5173，也支持 `ROADBOOK_PREVIEW_URL`。输出 36 张明暗主题、桌面和手机截图；`screenshots/redesign/verification.json` 同时记录页面错误、水平溢出与关键文字对比度。`tests/e2e/design-experience.spec.js` 验证日期边界与恢复、板块导航、字号持久化、手机当天入口与搜索键盘行为；既有测试继续验证 22 章、地图、预算、检查清单与打印。日地图补验使用 `node tools/screenshot-day-maps.mjs 320` 和 `390`，记录在 `screenshots/maps/`。自动测试之后仍应查看真实页面，尤其检查时间是否被断行、地图内部是否越界、标题是否遮挡，以及明暗切换后的文字对比度。本文提到的 `screenshots/` 目录为本地验收产物，2026-09-29 已清理，需要时按上述脚本重新生成。

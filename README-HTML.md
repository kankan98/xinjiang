## 网页能力

- 十天速查支持前后日切换、方向键、Home / End 和上次日期恢复，手机自动露出已选日期。
- 六张沿途点餐卡可直达对应章节；金额是四人规划参考，餐厅资料保留历史快照属性。
- 机票与主选住宿（含钟点房）已有金额 ¥16,075.92；默认试算 ¥26,864.92（含租车 ¥4,489 与能源 ¥1,500），仍有四类费用未填。两家备选仅替换相应一晚，报价与已付分开；清空钟点房恢复 ¥198、油电恢复 ¥1,500，填 0 表示不使用；旧自定义油耗估算迁移为总额。
- 七项行前检查与章节勾选只保存在当前浏览器，不代表订票、联系酒店或取得通行许可。
- 日间纸面、夜间阅读、搜索、抽屉目录、章节导航、地图预览及打印继续可用。
- 首页板块导航随滚动高亮，不修改 hash 路由；品牌按钮回到首页顶部。
- 手机“日程”直达每日速查，从每日章节打开时沿用对应日期；章节工具栏提供可保存的大字阅读（16 / 18px）。
- 搜索支持常用关键词、清空和键盘选择，搜索框的 Home / End 保留光标编辑功能。

`roadbook:planner:v3.9:*` 保存速查、预算、住宿方案比较、行前检查和阅读字号；`roadbook:check:v3.9:<章节 ID>` 保存正文勾选。新版重写了部分清单，旧版按序号保存的勾选不自动迁移，以免错误标成已完成。主题沿用 `roadbook:theme`。没有云同步；浏览器禁用存储时仅保留本页会话。

## 地图与事实边界

`DayRouteMap.vue` 先对原快照应用 `annotateDayRoutes`，再绘制路线。出租车、民宿接驳、火车、航班、区间车与自驾分开标注。松树头、写真等往返计两次；独库约 60 km 为条件自驾估算，不能当作已开放的区间车线路。

地图的图示公里数包括其标出的餐饮与市区短途，正文汇总是转场规划基线；原查询时间和正文排程可能略有不同，界面已说明。首站导航和单段链接分别使用实际端点，中文仅编码一次。日地图在手机默认收起，打印强制展开。

手动更新原地图数据可运行 `pnpm run generate:day-routes`，需要 `AMAP_KEY` 或已有本机连接配置；POI 详情、评分、营业时间与距离核验用 `node tools/amap-mcp.mjs` 走高德 MCP，两次查询的原始响应都缓存在 `tools/.cache/`。该命令不包含在日常构建中，也不会因为重新生成就把旧查询日期刷新为实时核验。

独库原引用的 2026-06-07 公安厅文件是征求意见稿。9 月 10 日补读天山网 6-18 正式发布报道及山西省交通运输厅 6-19 转载，补齐 6-25 起实施依据；10-09 当期继续／取消预约与当天开放仍另核。官方入口、原查询记录、编辑校审日期分别保留，不能混为“今天已确认”。
